# Lab A1 Android

- Sinh viên: Trần Tuấn Tú
- MSSV: 241A010591
- Lớp: Lập trình di động - INT4211

Ứng dụng Android minh họa vòng đời Activity: `onCreate`, `onStart`, `onResume`, `onPause`, `onStop`, `onRestart`, `onDestroy` và `onSaveInstanceState`.

Mở thư mục gốc dự án bằng Android Studio, chọn thiết bị và chạy cấu hình `app`. Trong Logcat, lọc theo `tag:A1_241A010591` để xem các sự kiện vòng đời. Giao diện có ba nút: **XÓA LOG** (ghi sự kiện yêu cầu xóa log), **GÂY LỖI** (chủ động tạo lỗi để quan sát), **THOÁT** (đóng Activity).
